# 애드센스 신청 전 점검

기준일: 2026-05-28

## 신청 전 필수 확인

- 홈(`/`)이 공개 콘텐츠 중심으로 보이는지 확인한다.
- 소개(`/about`), 문의(`/contact`), 개인정보처리방침(`/privacy`), 이용약관(`/terms`), 면책조항(`/disclaimer`)이 모두 정상 접근되는지 확인한다.
- 블로그(`/blog`)와 시장 해설(`/reports`) 목록이 비어 있지 않고 글 상세 페이지로 이동되는지 확인한다.
- 사이트맵(`/sitemap.xml`)에 실제 공개 글 URL이 모두 포함되는지 확인한다.
- robots(`/robots.txt`)에서 `/app`, `/api/`, 관리자성 페이지가 차단되어 있는지 확인한다.
- 운영 데이터 화면(`/app`)은 `noindex, nofollow`가 유지되는지 확인한다.
- 홈의 기준일과 오늘 시장 요약이 너무 오래되지 않았는지 확인한다.
- 공개 화면에 광고 클릭 유도, 수익 보장, 특정 종목 매수 권유 문구가 없는지 확인한다.

## 콘텐츠 기준

- 시장 해설은 최소 10개 이상 유지한다. 현재 목표 상태는 14개다.
- 시장 해설은 지수, breadth, 변동성, 수급, 데이터 품질, 랭킹 해석처럼 사이트 고유 판단 기준을 설명해야 한다.
- 블로그는 초보 투자자용 기초 설명과 리스크 관리 글을 유지한다.
- 각 글은 관련 글 2~3개를 내부 링크로 연결한다.
- 종목명이 들어가더라도 매수 권유가 아니라 관찰 후보와 정보 제공 목적으로 설명한다.

## 신청 직전 실행 체크

아래 명령은 로컬 소스 기준 점검용이다.

```powershell
node --check node\index.js
```

```powershell
@'
const fs=require('fs'); const path=require('path');
for (const section of ['blog','reports']) {
  const dir=path.join('node','content',section);
  const rows=fs.readdirSync(dir).filter(f=>f.endsWith('.md'));
  console.log(section, rows.length);
}
'@ | node
```

배포 후에는 브라우저 또는 `Invoke-WebRequest`로 아래 URL을 확인한다.

```powershell
Invoke-WebRequest -UseBasicParsing https://www.leetraderlab.com/
Invoke-WebRequest -UseBasicParsing https://www.leetraderlab.com/sitemap.xml
Invoke-WebRequest -UseBasicParsing https://www.leetraderlab.com/robots.txt
Invoke-WebRequest -UseBasicParsing https://www.leetraderlab.com/blog
Invoke-WebRequest -UseBasicParsing https://www.leetraderlab.com/reports
```

## 승인 신청 권장 상태

- Search Console에서 소유권 확인이 완료되어 있어야 한다.
- `/sitemap.xml` 제출 후 주요 페이지 색인 요청을 진행한다.
- 신청 전 최소 3~5일 동안 홈의 시장 요약이 최신 상태로 유지되면 더 좋다.
- 승인 전에는 광고 배치보다 콘텐츠 신뢰도, 정책 페이지, 색인 가능성을 우선한다.

## 승인 후 운영 원칙

- 광고는 본문 중간 1개, 글 하단 1개 수준으로 시작한다.
- 금융 정보 페이지에서는 광고보다 면책 문구와 정보 제공 목적을 더 명확히 유지한다.
- 새 시장 해설을 주 2~3개 이상 추가해 사이트가 방치되어 보이지 않게 한다.
- 오래된 시황 글은 최신 판단처럼 보이지 않도록 기준일을 명확히 둔다.
