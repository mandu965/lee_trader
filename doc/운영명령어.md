# 자동매매 운영 원칙
- 09:30은 본 실행, 10:00은 09:30 미성공 시 복구용 재시도 슬롯입니다.
- 09:30 실행이 성공하면 당일 10:00 신규 BUY는 실행하지 않습니다.
- SELL/TRIM/EXIT 실패분은 같은 날 재시도할 수 있지만, 매도 성공 자금을 10:00 신규 BUY로 즉시 재투입하지 않습니다.
- 신규 BUY는 하루 1회 성공을 상한으로 보고, 추가 진입 전략은 별도 정책으로 분리하기 전까지 사용하지 않습니다.
- 현재 자동매매는 실험적 소액 모드가 아니라 제한적 실운용 모드입니다.
- PILOT 제한 실운용 기준은 최대 신규 4종목, 총 신규 노출 35%, 종목당 신규 진입 12%입니다.
- 다만 max_holdings 8 제한과 기존 보유 수를 먼저 반영하므로, 항상 4종목을 새로 매수하는 것은 아닙니다.
- 손실 방어 기준은 -5% REVIEW, -8% TRIM, -12% EXIT 후보입니다.
- 수익 보호 기준은 +10% TRIM 후보입니다.
- confidence 데이터 누락은 자동 EXIT가 아니라 REVIEW로 보류합니다.
- PILOT 상태에서는 점수 기반 교체매매를 바로 실행하지 않고 REVIEW로 보류합니다.
