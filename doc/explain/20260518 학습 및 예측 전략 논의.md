### 문제 1 — 60d와 90d의 중복 ✅ 실측 완료

**실측 결과**: pred_return 0.71, pred_mdd 0.84, prob_top20 0.71

- 수익률(0.71): 완전 중복은 아님 — 90d 가중치 30~40%로 유지 합리적
- **MDD(0.84): 거의 중복 → 90d MDD 제거 후보**
- **prob_top20_90d: 점수에 아예 반영 안 됨 → 즉시 제거 가능**

---

### 문제 2 — 보유 기간 불일치

시스템 내부에서 **예측 기간과 실제 보유 기간이 다릅니다.**

| 모듈 | 실제 기준 보유 기간 |
|---|---|
| AI 자동매매 (현재 예측) | 60일 ~ 90일 |
| Rule 자동매매 | **20일** (RULE_MAX_HOLDING_DAYS 기본값) |
| AI 실제 포지션 평균 보유 | 미측정 (확인 필요) |

Rule이 20일 기준으로 운영되는데 AI 랭킹이 60d/90d 기준으로 정렬된다면,  
Rule이 AI 랭킹을 참조할 때 신호 기간 미스매치가 발생합니다.

**고민 방향**: `pred_return_20d`를 추가하여 단기 신호를 별도로 생성하고,  
Rule 모듈에서는 이를 우선 참조하게 구조를 분리.

---

### 문제 3 — MDD 예측의 신뢰성 ✅ 부분 확인

`pred_mdd_60d`는 60일 내 최대 낙폭을 예측합니다.

MDD는 **경로 의존적(path-dependent)**입니다.  
단순히 시작점과 끝점의 가격 차이가 아니라, 60일 안에서 최저점이 언제 어디에 형성되는지에 달려있습니다.

**실측 결과**: 실제 수익률 vs 실제 MDD 상관계수 = **0.17** (매우 낮음)  
→ 수익률이 높아도 MDD는 독립적으로 결정됨 → MDD를 수익률로 대체할 수 없음, 별도 예측 필요성 지지.

**미측정**: 예측값 vs 실현값 정확도(RMSE, 방향 일치율) — Walkforward 리포트에서 확인 필요.

**고민 방향 A**: MDD를 유지하되 예측 정확도를 먼저 측정하고, 나쁘면 `pred_vol_60d`(경로 독립적) 교체  
**고민 방향 B**: MDD 유지 + Quantile Regression으로 보완 (p10이 MDD보다 더 직관적인 리스크 지표)

### 문제 4 — prob_top20의 기준 모호성 ✅ 확인 완료

`prob_top20_60d`는 "60일 후 상위 20% 진입 확률"입니다.

## 2. 예측 타겟 개선 아이디어

### 아이디어 A — Sharpe Ratio 직접 예측 ⭐

**현재**: 수익률(return)과 MDD를 따로 예측 → 점수 공식에서 사람이 합산  
**개선**: `pred_sharpe_60d = pred_return_60d / pred_vol_60d` 를 타겟으로 학습

모델이 수익·리스크 trade-off를 내부에서 학습하게 됩니다.  
현재 점수 공식에서 ret_score와 risk_penalty를 수동으로 조합하는 것보다  
더 일관된 신호를 만들 수 있습니다.

**난이도**: 중간 (label_builder에서 sharpe 계산 추가 필요)  
**주의**: 변동성이 극단적으로 낮은 종목에서 Sharpe가 이상 급등할 수 있어 winsorize 필수

---

### 아이디어 B — Quantile Regression (분포 예측) ⭐⭐

**현재**: 점 예측 (60일 후 수익률 = x%)  
**개선**: 분포 예측

| 타겟 | 의미 |
|---|---|
| `pred_return_60d_p10` | 하방 10th percentile (최악의 경우) |
| `pred_return_60d_p50` | 중앙값 |
| `pred_return_60d_p90` | 상방 90th percentile (최선의 경우) |

LightGBM은 `objective='quantile'`을 기본 지원합니다.

**활용**:
- `p10` → `risk_penalty`에 직접 사용 (실제로 손실이 얼마나 날 수 있는지)
- `p90 - p10` (예측 불확실성) → 신뢰도 점수에 반영
- 이 방식으로 Calibration 문제도 자연스럽게 해결됨

**난이도**: 중간 (모델 3개로 늘어나지만 구조는 단순)

### 아이디어 E — 학습 전략 개선

#### E-1. Sample Weight (최근 데이터 중시)

오래된 데이터보다 최근 데이터에 더 높은 가중치를 부여합니다.  
시장 체제가 바뀌었을 때 과거 패턴이 노이즈가 되는 문제를 완화합니다.

```python
# 예시: 지수적 감쇠 가중치
days_old = (today - date).days
weight = exp(-decay_rate * days_old)
```

**난이도**: 낮음 (LightGBM `sample_weight` 파라미터 추가)  
**주의**: decay_rate 튜닝 필요 — 너무 강하면 학습 데이터 사실상 줄어들어 과적합

---

#### E-2. Purged K-Fold + Embargo

현재 `TimeSeriesSplit`은 미래 데이터 누출을 막지만,  
피처 생성 시 rolling window(예: 20일 이동평균)가 인접 날짜를 참조하면  
학습/검증 경계 부근에서 미묘한 leakage가 발생할 수 있습니다.

**개선**: 학습·검증 구간 사이에 embargo period(예: 20일)를 비워서 완전 차단.

```
학습 구간 | [embargo 20일] | 검증 구간
```

**난이도**: 중간 (`mlfinlab` 라이브러리 활용 또는 직접 구현)  
**효과**: 미미할 수도 있지만, 실거래 성과와 백테스트 괴리를 줄이는 데 기여

---

#### E-3. prob_top20 Calibration

LightGBM 분류기의 raw 확률은 일반적으로 잘 캘리브레이션되지 않습니다.  
`prob_top20_60d = 0.7`이라고 해서 실제로 70%가 Top20에 드는 게 아닐 수 있습니다.

현재 이 확률이 `operational_buy_gate`의 `confidence_score`에 영향을 주므로  
수치의 실제 의미가 정확해야 합니다.

**개선**: 학습 후 Isotonic Regression으로 후보정

```python
from sklearn.calibration import CalibratedClassifierCV
# 또는 학습 후 validation set으로 isotonic regression 적합
```

**난이도**: 낮음  
**효과**: 게이트 신뢰도 수치의 해석 정확도 개선

### 4-4. 60d vs 90d 합산 방식 (`final_score.py` 확인)

```python
# ret_score: 60d 70%, 90d 30%
base["ret_score"] = 100.0 * (0.7 * ret_rank_60 + 0.3 * ret_rank_90)
```

`label_builder.py`의 `HORIZONS = [30, 60, 90]` — **30일 레이블이 이미 생성되고 있습니다.**  
`final_score.py`의 `FINAL_SCORE_OPTIONAL_INPUTS`에도 `pred_return_30d`, `pred_mdd_30d`, `prob_top20_30d`가 선언되어 있습니다.

그러나 `compute_ret_and_pred_scores()`에서 30d는 **실제로 사용되지 않습니다.**  
레이블은 있지만 모델 학습 타겟에 포함된 상태인지 `model_train.py`에서 별도 확인 필요.

---

### 4-6. MDD 예측 정확도

predictions.csv(미래 예측)와 labels.csv(과거 실현값)는 날짜 구조상 바로 병합이 불가능합니다.  
MDD 예측 정확도는 **Walkforward 검증 결과**(`walkforward_acceptance.json`)에서 확인하거나,  
과거 예측을 보존한 별도 아카이브에서 측정해야 합니다.

현재 검증 방법이 없다는 것 자체가 문제 — MDD 예측이 실제로 좋은지 나쁜지 모르는 상태로 운영 중.

## 5. 발견을 반영한 타겟 재설계 제안

### 현재 타겟의 실질적 문제 정리

| 타겟 | 문제 | 권고 |
|---|---|---|
| `pred_return_60d` | 없음 | 유지 |
| `pred_return_90d` | 60d와 0.71 상관 — 부분 중복 | 유지 (합산 가중치 30%라 비용 대비 OK) |
| `pred_mdd_60d` | 예측 정확도 미검증, 경로 의존적 | 유지하되 정확도 측정 후 재판단 |
| `pred_mdd_90d` | 60d와 0.84 상관 — 거의 중복 | **제거 후보** — 절감된 학습 비용을 다른 타겟에 활용 |
| `prob_top20_60d` | 없음 | 유지 |
| `prob_top20_90d` | **점수에 전혀 반영 안 됨** | **즉시 제거 가능** — 현재 사실상 데드코드 |

**즉시 제거해도 점수에 영향 없는 것**: `prob_top20_90d`

---

### 절감된 학습 자원으로 추가할 수 있는 타겟

`prob_top20_90d`를 제거하면 모델 1개 분량의 학습 자원이 확보됩니다.  
이것을 다음 중 하나로 교체하는 것이 합리적입니다.

| 후보 | 의미 | 근거 |
|---|---|---|
| `pred_return_30d` | 30일 후 수익률 | 레이블이 이미 존재 (`label_builder.py`), Rule 20일 기준에 근접 |
| `pred_return_60d_p10` | 60일 후 하방 10th percentile | MDD보다 경로 독립적, risk_penalty 개선 |
| `pred_sharpe_60d` | 60일 Sharpe Ratio | 수익·리스크 통합 신호 |
