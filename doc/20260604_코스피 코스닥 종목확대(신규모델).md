## 3. 연구 설계 — 4단계 (단계마다 kill-switch)

```
Phase 0  유동성 정찰 (수 시간, 백필 0)              ── ✅ 완료·통과 (§5)
  └ 100~200위 거래대금 분포 vs top-100, 포지션 참여율, 백필 규모
  └ KILL: 거래가 불가능할 만큼 얇으면 종료

Phase 1  데이터 백필 (수 일)                        ── ▶ 다음

Phase 2  섀도 백테스트 (핵심 GO/NO-GO)
  └ 기존 top-100 모델 그대로 적용 = "엣지가 전이되는가" 순수 테스트

  └ KILL: 비용 차감 후 알파가 top-100을 분명히 상회하지 못하면 → 연구 자산으로만 남기고 중단

Phase 3  전용 모델 (Phase 2 통과 시에만)
  └ 중형주 전용 학습 + 자체 walkforward + 자체 게이트 → paper trading
  └ 시점: CLAUDE.md 섹션 7의 2026-08~09 재검토 창 (라이브 2~3개월 누적 후)
```

## 4. GO / NO-GO 합격선 (규율)

> **Phase 2에서 중형주 비용차감 후 알파가 top-100을 "분명히 상회"해야 라이브 2번째 모델로 간다.**
> 단순히 "비슷하다"면 운영 복잡도 2배(모델·게이트·자본배분)를 정당화 못 하므로,
> 연구 자산으로만 남기고 라이브화는 보류한다.

이로써 열린-결말 작업이 아니라, 수 일 투자로 명확한 GO/NO-GO를 얻는 거래가 된다.

## 7. Phase 2 — 1차 시도: ⛔ 무효 (in-sample 누수 + 생존편향)

스크립트: [midcap_phase2_backtest.py](../python/research/midcap_phase2_backtest.py)
산출물: [phase2_portfolio_midcap.csv](../data/research_midcap/phase2_portfolio_midcap.csv), [phase2_portfolio_top100.csv](../data/research_midcap/phase2_portfolio_top100.csv)

### 1차 결과 (2023-06~2026-05, 60d 비중첩)

| 유니버스 | rank-IC(IR) | top10 60d net | 연환산 | 누적 | bench gross |
|---|---:|---:|---:|---:|---:|
| top-100 | **0.498 (3.57)** | 74.8% | 314% | 41,770% | 13.4% |
| midcap | 0.160 (1.51) | 18.8% | 79% | 482% | 6.5% |

### ⛔ 두 결과 모두 무효 — 이 숫자로 판단 금지

1. **In-sample 누수 (치명적)**: 운영 모델 `trained_at=2026-06-03`, 학습 라벨 범위 **2023-04~2026-04**. 백테스트 기간이 학습 기간과 거의 완전 중첩 → top-100은 모델이 정답을 학습한 **in-sample**. IC 0.498(실전은 ~0.05)이 이를 증명. midcap은 out-of-universe라 덜하지만 같은 기간 regime/factor를 모델이 이미 학습.
2. **생존편향**: 유니버스가 *오늘(2026-06)* 기준 100~200위. 2023년에 탈락한 종목 제외 → 절대수익 대폭 부풀림. 대형주는 이탈 적어 편향이 작고, 중형주는 편향이 큼 → 비교가 midcap에 불리하게 왜곡.

→ midcap vs top-100 = in-sample vs out-of-universe = **사과-오렌지**. GO/NO-GO 불가.

### 유일하게 (약하게) 시사적인 점

midcap이 학습 유니버스에 한 번도 없었는데 IC 0.16(양수, IR 1.51)이 나온 것은, 모델이 학습한 팩터 구조가 미지의 종목에도 일부 신호를 준다는 **약한 전이 가능성**. 단 in-period·생존편향으로 확증 불가.

### Phase 2b — 유효한 재설계 (다음 단계)

1. **Out-of-sample 모델**: top-100 + labels.csv로 **조기 컷오프**(예: 라벨 ~2024-12) 모델 학습 → midcap 2025~2026 적용. 시간·유니버스 동시 OOS. (model_train.py 재사용 가능)
2. **(이상적) Point-in-time 유니버스**: 과거 각 시점의 시총 100~200위를 복원(전 종목 historical mcap 필요) → 생존편향 제거. 데이터 부담 큼 → 2b가 유망하면 착수.

긍정 요소: 데이터·피처·스코어링·백테스트 **파이프라인 전체가 작동**함을 확인. 누수만 제거하면 유효한 답을 낼 수 있는 상태.

## 8. Phase 2b — OOS 모델로 재실행 (유효) → 전이 **미입증 (사실상 NO-GO)**

스크립트: [midcap_train_oos_model.py](../python/research/midcap_train_oos_model.py) (조기 컷오프 학습, 운영 model.pkl·산출물 미접촉).
top-100 features/labels로 **조기 컷오프** 모델 학습 → 컷오프 이후(미관측) 구간만 midcap/top-100 평가.

### 결과 (2개 컷오프 — 재현성 점검)

| 컷오프 | OOS 창 (기간수) | midcap IC(IR) | midcap top10 α | top-100 top10 α |
|---|---|---:|---:|---:|
| 2024-09-30 | 2025-01~2026-03 (5) | +0.026 (0.25) | **+7.79%p** | +3.05%p |
| 2024-03-31 | 2024-07~2026-03 (7) | +0.041 (0.40) | **−0.24%p** | +5.82%p |

### 판정: 전이 **미입증** — "top-100을 분명히 상회" 합격선 불충족

- **midcap top-N 알파가 창에 따라 부호가 뒤집힘**(+7.8%p → −0.2%p) = **노이즈 수준**, 강건한 엣지 아님.
- midcap rank-IC는 두 창 모두 미약 양수(+0.03~0.04)이나 **IR 0.25~0.40 = 통계적으로 유의하지 않음**(60일 중첩 고려 시 사실상 독립표본 5~7개).
- 1차의 IC 0.5·누적 482%는 전부 in-sample 누수였음이 확정.

### 양방향 잔여 caveat (정직하게)

- (엣지 과소평가 가능) 조기 컷오프 OOS 모델은 운영 모델보다 데이터 적고 recency 가중 이점 없음 → top-100 OOS도 약하게 나옴.
- (엣지 과대평가 가능) 유니버스가 *오늘* 기준 → 생존편향 잔존(절대수익 부풀림).

### 결론 / 다음 분기점

**현 증거로는 top-100 모델의 엣지가 중형주로 강건하게 전이된다고 볼 수 없음 → 라이브 중형주 모델 보류(NO-GO).**
단, midcap IC가 두 창 모두 *미약 양수*로 일관된 점은, 별개 가설인 **중형주 전용 학습 모델(Phase 3)** 에는 여지를 남김(전이 실패 ≠ 전용모델 실패). 추진 시: PIT 유니버스로 생존편향 제거 + 중형주 자체 학습 + 더 긴 OOS 누적 후 재평가. 추진 안 하면 연구 자산으로 보존.

**메타 교훈**: Phase 0 유동성 OK + 1차 백테스트의 화려한 수치(IC 0.5)에 속았다면 거짓 GO였을 것. 누수 제거(OOS) 후에야 진짜 답(미입증)이 드러남 — 규율 있는 검증의 가치.

### PIT 유니버스 복원 — 생존편향 정량화 ([midcap_pit_universe.py](../python/research/midcap_pit_universe.py))

16개 분기말 시점의 시총 101~200위 복원 결과:
- 과거 합집합 **784종목**, 현재 200과 교집합 **178**, dropout **606** → 밴드 **77% churn**.
- 즉 Phase 2/2b는 784 중 178(생존자)만 평가 → 생존편향 심각. "전이 미입증" 결론 강화(편향이 midcap을 부풀렸는데도 노이즈).
- **전략적 함의**: 100~200위 밴드는 분기 단위로 대규모 교체 → 라이브 시 유니버스 churn·리밸런싱 부담 큼(별도 고려사항).

### Phase 3(전용모델)를 하려면 — 견적

PIT 유니버스(784종목)로 평가해야 유효 → dropout 606종목 추가 백필 필요(가격 빠름 / flow·short는 동일 날짜에 wider target 재실행 ~40분 / DART ~40분) + 라벨 + 중형주 전용 학습 + 워크포워드. ≈ Phase 1 한 사이클(784종목 규모) 재실행 + 학습/평가. 산출물·코드는 전부 재사용 가능.

## 9. Phase 3 — 중형주 전용모델 (PIT + walk-forward) → ⛔ **확정 NO-GO**

스크립트: [midcap_phase3_dedicated.py](../python/research/midcap_phase3_dedicated.py)
PIT 806종목 가격 백필([prices_pit_raw.csv](../data/research_midcap/prices_pit_raw.csv), 792,521행/805종목) →
중형주 *전용* LightGBM(price-only 24피처)을 **분기 재학습 walk-forward**(누수 0) + **PIT 유니버스**(생존편향 0)로 평가.

### 결과 (OOS 2024-07~2026-03, 분기 재학습 8회)

| 지표 | 값 |
|---|---:|
| rank-IC (ML pred) | +0.052 (IR 0.38, n=81) — 유의하지 않음 |
| rank-IC (naive ret_120d) | +0.007 |
| top10 60d net / **alpha** / hit | 3.09% / **−4.70%p** / 46% |
| top20 60d net / **alpha** / hit | 5.42% / **−2.37%p** / 52% |
| PIT 유니버스 벤치 60d | 7.79% |

### 판정: 확정 NO-GO

- 약한 양의 IC(0.05)조차 **실제 거래하는 top-N에선 음의 알파**(−4.7%p)로 뒤집힘 → 모델 고확신 종목이 균등분산보다 **못함**. 경제적 가치 음(−).
- 생존편향·누수를 **둘 다** 제거한, 가능한 가장 깨끗한 테스트. 결과는 명확히 부정.
- 진행 경로 일관: naive(IC 0.5, 누수) → OOS(노이즈) → PIT+전용(top-N 알파 음) = **바이어스 제거할수록 악화 → 알파 없음의 확증**.

### 최종 결론

**코스피·코스닥 100~200위 단일종목 확장은 기각.** 전이도, 전용모델도 모두 미입증/음(−). 시스템 확장은 [시스템로드맵.md](시스템로드맵.md) "🧩 확장 방향성"의 ①자본 → ②모델심화 → ③리스크 → ④ETF 순으로(폭 아닌 깊이). 본 연구 자산(코드·데이터·문서)은 보존 — 2026-08~09 라이브 데이터 재검토 시 참고용.
