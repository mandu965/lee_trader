## 1. 모델 학습 변경 — Confidence Calibration OOF 적용

### 변경 파일
- [python/model_train.py](../python/model_train.py)
  - line 13: `IsotonicRegression` import 추가
  - line 14-19: 사용하지 않게 된 `CalibratedClassifierCV`/`FrozenEstimator` import 제거
  - line 612-690: CV 루프에서 OOF 예측 수집 + IsotonicRegression 직접 학습

### 변경 이유
기존 calibration이 누설 발생:
- `cls.fit(X, y)`로 전체 데이터 학습
- `last_va_mask`(이미 X에 포함됨)로 calibration
- → calibrator가 학습 데이터로 fit되어 confidence가 실제보다 낙관적

### 새 방식 (Out-of-Fold)
1. CV 각 fold에서 cls_i가 validation set 예측
2. 모든 fold의 OOF 예측을 oof_proba에 수집
3. 최종 cls는 전체 데이터로 학습 (데이터 손실 없음)
4. `IsotonicRegression`을 OOF 예측값(누설 없음)으로 학습

### 적용 결과
- 모델 재학습 완료 (`OOF n_cal=135573, 3 folds`)
- 새 예측 분포: 평균 0.027 → 0.154 (base rate ~20%에 근접 = 정직)
- 표준편차 좁아짐 (0.069 → 0.026)
- 종목 순위 상관: Pearson 0.63, Spearman 0.77 (순위 보존)

- `data/model.pkl.backup_20260529_calibration`
- `data/model_feature_importance.json.backup_20260529_calibration`

## 5. ai_adjusted_score 공식 v2 적용

### 변경 파일
- [python/build_ai_filtered_top_candidates.py](../python/build_ai_filtered_top_candidates.py) — `build_adjusted_score()` 함수

### 변경 이유
v1 공식의 3가지 의문점:
1. **entry_quality 과대 가산**: `× 0.20`이 +16점 수준 → final_score 의미를 흐림
2. **ret_10d/ret_5d 단위 미스매치**: fraction(0.05) × 0.30 = 0.015점 → 사실상 효과 없음 (단위 의도 vs 코드 불일치 가능성)
3. **risk_penalty 이중 차감**: final_score에 이미 비례 차감되었는데 또 ×0.50 차감

### 새 공식 v2
```
adjusted = final_score
         + entry_quality_bonus    # (entry_quality_score - 70) × 0.10, ±3점 내외
         - overheat_penalty       # 구간형 단기 과열 페널티 (최대 -7점)
         - risk_extra_penalty     # 구간형 위험 추가 차감 (최대 -5점)
adjusted = clip(adjusted, 0, 100)
```

#### 구간형 페널티 (이전 비례 차감 대체)
```
overheat_penalty:
    ret_5d  >= 12% : +3
    ret_5d  >=  8% : +1.5
    ret_10d >= 20% : +4
    ret_10d >= 12% : +2
risk_extra_penalty:
    risk_penalty >= 18 : +5
    risk_penalty >= 15 : +2
```

#### 임계값 정합성
- 구간 임계값(8%/12%/20%, 15/18)이 `build_ai_entry_quality_score.py`의 WATCH/BLOCK 임계값과 부합 → Stage 간 일관성

### 적용 결과 (2026-05-29 측정)
| 항목 | v1 | v2 |
|---|---|---|
| Top 5 중복 | - | 3/5 (60%) |
| Top 1 (083650) | 1위 유지 | 1위 유지 |
| 단기 급등 종목 (018880, ret_5d 17%) | Top 5 (4위) | Top 10 외(9위) ← 페널티 발동 |
| 점수 변동 폭 | ±20점 | ±7점 내 (안정) |
