# 2026-04-18 운영 상태 및 PILOT 구현 메모

## 현재 운영 상태

- 현재 코드 기준 실운용 상태는 `PILOT 제한 실운용`까지 구현된 상태입니다.
- 현재 `WATCH`에서는 아래 제한 규칙만 허용합니다.
  - 최대 `2종목`
  - 총 신규 노출 `15%`
  - 종목당 신규 진입 상한 `8%`
- 현재 `PILOT`에서는 아래 제한 규칙을 허용합니다.
  - 최대 `4종목`
  - 총 신규 노출 `30%`
  - 종목당 신규 진입 상한 `12%`
- `HOLD`, `BLOCK`에서는 신규 진입을 허용하지 않습니다.
- `BUY_ALLOWED`는 정식 자동매수 승인 단계로 유지합니다.

## 구현 상태

- `PILOT`은 문서 제안이 아니라 현재 코드에 구현된 상태입니다.
- 반영 범위는 아래와 같습니다.
  - `build_operational_buy_gate.py`: `PILOT` 상태 산출
  - `apply_execution_policy.py`: `PILOT` 제한 진입 집행
  - `build_trade_intents.py`: `PILOT` 기준 intent 생성
  - `build_live_order_preview.py`: `PILOT` gate 해석 반영
  - `config/production_v1.yaml`: `PILOT` 한도 및 조건 설정

## 현재 기준 문장

> 현재 운영 상태는 `WATCH 제한 진입 + PILOT 제한 실운용`까지 구현되어 있고, `BUY_ALLOWED`는 그 위의 정식 승인 단계입니다.
