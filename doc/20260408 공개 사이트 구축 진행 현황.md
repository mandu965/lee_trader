## 1. 작업 목적

현재 프로젝트는 운영 도구와 분석 화면 중심 구조입니다.

기존 성격:

- 수동매매 화면

이 구조만으로는 애드센스 승인용 사이트로 보기 어렵기 때문에, 아래 방향으로 확장 작업을 진행했습니다.

- 공개 콘텐츠 레이어 추가

- 리포트 / 블로그 목록 및 상세 글 구조 추가
- 검색엔진용 메타 정보와 sitemap/robots 준비

효과:
