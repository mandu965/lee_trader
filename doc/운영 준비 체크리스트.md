# 운영 준비 체크리스트

## 목적
- 현재 단계의 목표는 `정식 자동 운영`이 아니라 `운영 readiness 판단을 위한 이력 축적`입니다.
- 따라서 매일 파이프라인을 안정적으로 돌리고, 산출물과 snapshot/history가 계속 누적되는지 확인하는 것이 핵심입니다.

## 현재 해석 원칙
- 실운영 점수 해석은 `live_score`를 기준으로 봅니다.
- `final_score`, `final_score_v3`는 계산 결과 / 비교용 컬럼으로 유지합니다.
- 지금은 `live_uses_theme`가 바로 실운영으로 켜진 상태가 아니라는 전제에서 운영 준비를 진행합니다.

## 데일리 실행 순서
```powershell
docker compose build --no-cache --progress=plain python-pipeline
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

docker compose up -d python-pipeline
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

python python/run_operational_refresh.py
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

docker compose up -d --build node-api
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
```

## 매일 확인할 항목
### 1. 실행 성공 여부
- `run_operational_refresh.py`가 오류 없이 끝났는지 확인
- `node-api`가 정상 기동됐는지 확인
- `ranking_final.csv`, `daily_recommendations.json` 날짜가 최신일인지 확인

### 2. 핵심 산출물 확인

- [daily_recommendations.json](D:/ai/Lee_trader/serving/daily_recommendations.json)
- [operational_buy_gate.json](D:/ai/Lee_trader/outputs/operational_buy_gate.json)

- [ranking_snapshot_inventory.md](D:/ai/Lee_trader/data/history/ranking_snapshot_inventory.md)

### 3. readiness 누적 확인
- `ranking_snapshot_inventory.md`에서 snapshot count가 증가하는지 확인
- `matured snapshot count 60d`가 언젠가 0에서 증가하는지 확인
- `confidence calibration readiness 60d`가 `WAIT`에서 `READY`로 바뀌는지 확인

### 4. buy gate 상태 확인
- `operational_buy_gate.json`의 `overall_status` 확인
- 계속 `HOLD`인지, `WATCH`로 상향되는지 확인
- `matured benchmark dates`, `confidence_v2 trusted ratio`, `walkforward_acceptance`를 같이 확인

### 5. 수동매매 관점 확인
- `/api/ranking` 또는 수동매매 화면에서 `live_score` 상위 종목 확인
- `PROMOTION_READY`, `WATCHLIST`, `BLOCK` 분포 확인
- 실제 매수 검토 종목은 1~2개 수준으로만 압축
- 시초가 갭 과열, 거래대금 부족, 테마 과열 종목은 보류

### 1. KPI 추세 확인
- `score_kpi_monitor.md`에서 ALERT 항목이 줄어드는지 확인
- `corr_final_tech_score`, `overlap_final_*`, `corr_final_risk_penalty_abs` 추세 확인

- snapshot 누적 일수가 계속 쌓이는지 확인
- `matured benchmark dates`가 증가하는지 확인

- 추천 상위 종목이 과도하게 테마/섹터에 쏠리는지 확인
- 실제 체결가와 추천 시점 가격 차이가 큰지 확인

## 운영 전환 판단 기준
- `operational_buy_gate.json`이 더 이상 구조적으로 `HOLD`만 반복하지 않음
- `ranking_snapshot_inventory.md`에서 `confidence calibration readiness 60d: READY`
- matured benchmark / forward evidence가 최소 기준 이상 확보됨
- `live_score` 기준 API, DB, 화면 해석이 일치함
- 소액 수동 검증 결과가 시스템 기대와 크게 어긋나지 않음
