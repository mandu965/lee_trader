## 1. 문서 범위

- 한국 주식 운영 파이프라인 데이터
- 한국 자동매매/계좌/체결/리뷰 데이터
- 미국 주식 연구/페이퍼트레이딩 데이터
- CSV, DB, 주요 JSON 산출물 기준

주의:

- `ranking_final.csv`는 파생 컬럼이 매우 많아 핵심 그룹 중심으로 정리한다.
- 컬럼명이 수시로 늘어나는 실험성 산출물은 “핵심 컬럼 + 파생 컬럼군”으로 묶는다.
- 실제 점수 상세 컬럼은 [doc/score_column_definitions.md](/d:/ai/lee_trader/doc/score_column_definitions.md)와 함께 보는 것이 맞다.
