# Lee Trader KR 데이터 카탈로그

작성일: 2026-05-25  
범위: 한국 주식(KR) 데이터만 정리

---

## 1. 목적

이 문서는 KR 시스템이 실제로 다루는 데이터 항목을 파일과 도메인 기준으로 정리한다. 미국 주식 데이터는 제외한다.

정리 원칙:

- `현재 활성`: 현재 운영 산출물에 직접 반영되는 항목
- `보조 활성`: 운영 파일에는 남지만 주로 설명/진단/리포트용인 항목
- `계산식`: 코드에 드러난 핵심 계산 로직만 간단히 적고, 전체 구현은 스크립트를 기준으로 본다.

| 컬럼 | 의미 |
| --- | --- |
| `flow_foreign_net_5d` | 외국인 5영업일 순매수 누적 |
| `flow_foreign_net_20d` | 외국인 20영업일 순매수 누적 |

- `flow_foreign_net_5d` = 외국인 순매수 5영업일 rolling sum
- `flow_foreign_net_20d` = 외국인 순매수 20영업일 rolling sum
- `flow_inst_net_5d` = 기관 순매수 5영업일 rolling sum
- `flow_inst_net_20d` = 기관 순매수 20영업일 rolling sum

점수 사용 핵심:

- `flow_score = 0.6 * percentile(flow_foreign_net_5d) + 0.4 * percentile(flow_inst_net_5d)`

전체 컬럼:

`date, code, close, ret_1d, ret_5d, ret_10d, mom_20, ret_60d, ret_120d, high_52w_ratio, ma_5, ma_20, ma_60, close_over_ma20, vol_20, vol_60, rsi_14, volume, volume_ratio_5d, volume_ratio_20d, value_ratio_5d, value_ratio_20d, volume_score, liquidity_score, vol_ma_20, vol_ratio_20, quality_score, quality_factor_count, quality_missing_ratio, quality_score_confidence, flow_foreign_net_5d, flow_foreign_net_20d, flow_inst_net_5d, flow_inst_net_20d, revenue_growth_yoy, op_income_growth_yoy, roe_yoy, sector_rel_momentum_20d, fin_momentum_phase, fin_momentum_score, fin_risk_score, fin_turnaround_score, fin_hard_risk, short_ratio, short_ratio_5d_chg, short_ratio_20d_avg`

### 가격/수익률

- `close`
- `ret_1d`
- `ret_5d`
- `ret_10d`
- `mom_20`
- `ret_60d`
- `ret_120d`
- `high_52w_ratio`

계산식 핵심:

- `ret_*` = `close.pct_change(n)`
- `high_52w_ratio` = `close / rolling_max(252일, min_periods=60)`

### 이동평균/기술

- `ma_5`
- `ma_20`
- `ma_60`
- `close_over_ma20`
- `rsi_14`

계산식 핵심:

- `ma_*` = 단순 이동평균
- `close_over_ma20` = `close / ma_20 - 1`
- `rsi_14` = 14일 RSI(EWM 기반)

### 변동성

- `vol_20`
- `vol_60`
- `vol_ma_20`
- `vol_ratio_20`

계산식 핵심:

- `vol_20`, `vol_60` = `ret_1d` rolling std
- `vol_ma_20` = `volume` 20일 평균
- `vol_ratio_20` = `volume / vol_ma_20`

### 거래량/유동성

- `volume`
- `volume_ratio_5d`
- `volume_ratio_20d`
- `value_ratio_5d`
- `value_ratio_20d`
- `volume_score`
- `liquidity_score`

계산식 핵심:

- `volume_ratio_5d` = `volume / vol_ma_5`
- `volume_ratio_20d` = `volume / vol_ma_20`
- `value_ratio_5d` = `value_traded / value_ma_5`
- `value_ratio_20d` = `value_traded / value_ma_20`
- `volume_score`, `liquidity_score` = 날짜별 percentile 복합 점수

활성 상태 메모:

- 거래량/유동성 계층은 랭킹 점수와 후보 필터 양쪽에 모두 직접 사용된다.

- `quality_score_confidence`
- `revenue_growth_yoy`

계산식 핵심:

- `revenue_growth_yoy`, `op_income_growth_yoy`, `roe_yoy`는 코드별 전년 대비 변화율 또는 변화량으로 계산된다.

### 섹터/재무모멘텀/공매도
