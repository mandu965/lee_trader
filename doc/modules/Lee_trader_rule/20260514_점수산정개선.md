## 2. 전략 구조 요약

### 2-1. 진입 공식 (base_conditions — AND 10개)

| 조건 | 내용 |
|---|---|
| `close > ma_20` | 단기 추세 — 현재가가 20일 이평선 위 |
| `ma_20 >= ma_60` | 중기 추세 정렬 — 골든크로스 |
| `ret_5d > 0` | 5일 수익률 양수 |
| `mom_20 > 0` | 20일 모멘텀 양수 |
| `RSI ∈ [45, 80]` | 과매도/과매수 제외 (**수정됨**, 기존 75) |
| `volume_ratio_20d >= 1.2` | 거래량 20일 평균 대비 20% 초과 |
| `trading_value_ratio_20d >= 1.1` | 거래대금 비율 10% 초과 |
| `trading_value_ma_20 >= 5억` | 유동성 최소 기준 (paper 기준) |
| `expected_gap.abs() <= 3%` | 시가 갭 위험 제외 |
| `market_entry_allowed` | 시장 레짐 통과 |

과열 차단 조건 (`overheated` — OR):
- RSI > 80, close_over_ma20 > 20%, ret_5d > 25%, vol_20 상위 10%

### 2-2. 점수 구조 (rule_score_v3 — 실제 적용 점수)

| 컴포넌트 | 가중치 | 내용 |
|---|---|---|
| trend | 30% | close>ma20, ma20>=ma60, mom_20, ret_5d 퍼센타일 |
| liquidity | 25% | 거래대금 절대/비율 순위 |
| stability | 15% | 변동성 낮음, RSI 적정, MA 근접도 |
| regime | 15% | 시장 레짐 상태 |
| flow | 15% | 외국인 60% + 기관 40% 순매수 5일 퍼센타일 |

진입 신호:
- `entry_signal`: base_conditions AND NOT overheated AND (rule_score ≥ 70 OR rule_score_v3 ≥ 65)
- `strong_entry_signal`: base_conditions AND NOT overheated AND (rule_score ≥ 70 AND rule_score_v3 ≥ 60)

## 4. 문제점 분석 (전략 전체)

### 4-1. 버그 — 즉시 수정

#### [Bug 1] RSI 진입 구간 dead zone

```python
# 변경 전 (버그)
& (rsi.between(45, 75))   # 진입 허용 상한: 75
overheated = (rsi > 80)   # 과열 차단 하한: 80
```

RSI 75 초과 ~ 80 이하 구간이 **진입 조건 탈락 + 과열 조건 미해당**으로  
어떤 로직에도 포함되지 않는 논리 공백이 발생합니다.

예: RSI = 77인 강한 모멘텀 종목 → 이유 없이 걸러짐

```python
# 변경 후 (수정)
& (rsi.between(45, 80))   # 과열 임계값(80)과 정렬
```

#### [Bug 2] 트레일링 스탑 — 이익 보호가 아닌 손실 확정

```python
# 변경 전 (버그)
trailing_stop_min_profit_pct = 0.03   # 최소 수익 +3% 이상일 때 발동
trailing_stop_pct = 0.04              # 최고점 대비 -4% 하락 시 청산
```

수익 시뮬레이션:
```
최고 수익 +3% 도달 → -4% 하락 → 현재 수익률 = -1% → 손실로 청산
```

이익 보호를 위한 로직이 오히려 손실을 확정시키는 설정입니다.

```python
# 변경 후 (수정)
trailing_stop_min_profit_pct = 0.05   # 최소 수익 +5% 이상일 때 발동
trailing_stop_pct = 0.025             # 최고점 대비 -2.5% 하락 시 청산
```

수익 시뮬레이션:
```
최고 수익 +5% 도달 → -2.5% 하락 → 현재 수익률 = +2.5% → 수익 확정 청산
```

### 4-2. 설계 이슈 — 2단계 검토 대상

#### [Issue 1] flow 가중치 과소 반영 (15%)

한국 주식시장에서 외국인·기관 수급은 가장 강력한 알파 팩터 중 하나입니다.  
(Kim & Wei 2002, Choe, Kho & Stulz 1999 등 학술 연구 다수)

현재 flow 컴포넌트가 15%에 불과하여 수급이 나쁜 종목이 기술적 조건만으로 선정되는 경우가 있습니다.  
**제안**: 25~30%로 상향하면 "예상과 다른 종목" 출현이 감소할 것으로 예상됩니다.

#### [Issue 2] 보유 기간(10일)과 백테스트 평가 지평선(20일) 불일치

백테스트는 `ret_d20` (20일 수익률)을 주요 지표로 평가하지만,  
실제 포지션은 `max_holding_days = 10`으로 강제 청산합니다.

모멘텀 팩터의 수익은 학술적으로 3주~3개월에 걸쳐 발현됩니다 (Jegadeesh & Titman 1993).  
10일 한계가 전략 자체의 엣지를 조기에 차단할 가능성이 있습니다.  
**제안**: 20일로 연장하여 백테스트 지평선과 정렬.

#### [Issue 3] 거래대금 기준이 낮아 소형·테마주 노출

현재 paper 기준 `trading_value_ma_20 >= 5억`은 소형주까지 포함됩니다.  
일 평균 거래대금 5억원 종목은 단기 세력에 의해 기술적 지표가 쉽게 조작될 수 있습니다.  
**제안**: paper 10억, live 30억으로 상향하여 노이즈 감소.

#### [Issue 4] 신호 강도와 포지션 크기 무관

rule_score_v3 = 68점이든 95점이든 동일하게 `new_entry_weight = 5%`를 배정합니다.  
신호 신뢰도가 포지션 크기에 반영되지 않아 자본배분 효율이 낮습니다.  
**제안**: 4~7% 비례 배분 (신호 강도 × 포지션 크기 연동).

#### [Issue 5] 시장 레짐 필터가 이진(binary) 전환

2/3 조건 충족 시 전체 매수 차단. KOSPI 약세장에서도 방산·헬스케어 등  
개별 섹터 강세 기회가 존재하는데, 이를 모두 차단합니다.  
**제안**: 차단 대신 `max_positions` 감소(5→3)로 약화(dampening) 처리.

#### [Issue 6] 거래량 이중 카운팅

`volume_ratio_20d >= 1.2`는 base_conditions 통과 조건 (binary).  
동시에 점수 계산에서 `percentile_by_date(out, "volume_ratio_20d")`로 다시 반영.  
거래량 급등 종목에 이중 가산점 → 테마주·작전주 선정 가능성.
