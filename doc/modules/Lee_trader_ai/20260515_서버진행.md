## Step 6 — ranking_builder.py 실행 (Phase 4 + Phase 5 shadow 확인)

```bash
python ranking_builder.py
```

**Phase 5 — shadow ranking 검증:**
```bash
python -c "
import pandas as pd
df = pd.read_csv('data/ranking_final.csv')

# shadow_fin_rank_diff: 양수 = 재무모멘텀 적용 시 순위 상승
print('=== fin_momentum_phase 분포 ===')
print(df['fin_momentum_phase'].value_counts())

print('\n=== shadow_fin_rank_diff 통계 (순위 변화) ===')
print(df['shadow_fin_rank_diff'].describe())

print('\n=== 순위 크게 변하는 종목 (상위 10) ===')
print(df[['code','rank_final','fin_momentum_phase','shadow_fin_rank','shadow_fin_rank_diff','shadow_fin_final_score']]
      .sort_values('shadow_fin_rank_diff', ascending=False).head(10).to_string(index=False))

print('\n=== hard_risk 종목 ===')
print(df[df['fin_hard_risk'] > 0][['code','rank_final','fin_momentum_phase','shadow_fin_hard_risk_triggered']].to_string(index=False))
"
```

**판단 기준:**
- `shadow_fin_rank_diff` 절대값 평균 < 3 이면 overlay 효과 안정적
- `shadow_fin_rank_diff` 양극단(> ±10) 종목 5개 이상이면 overlay 강도 재검토
- `hard_risk` 종목 중 현 보유 종목 있으면 즉시 보고

## Step 7 — 모델 재학습

```bash
python -c "
import pandas as pd
df = pd.read_csv('data/features.csv')
required = ['flow_foreign_net_5d','flow_foreign_net_20d','ret_60d','ret_120d',
            'high_52w_ratio','revenue_growth_yoy','sector_rel_momentum_20d']
for c in required:
    ok = c in df.columns and df[c].isna().mean() < 0.30
    print(f\"{'OK' if ok else 'FAIL'} {c}: NaN {df[c].isna().mean():.1%}\" if c in df.columns else f'FAIL {c}: 컬럼 없음')
```
