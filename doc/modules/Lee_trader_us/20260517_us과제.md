## 다음 과제

### ✅ Phase F — 신규 피처를 Rule Score에 반영 (2026-05-17 완료)

**반영 결과**:

| 신호 | 반영 방식 | 구현 위치 |
|---|---|---|
| `rsi_14` | 40~75 헬시존 +2, >82 오버바이 -2 | momentum_score / risk_score |
| `high_52w_ratio` | ≥0.85이면 +2 | momentum_score |
| `sector_rank_pct` | ≥0.60이면 +2 | momentum_score |
| `analyst_target_upside` | >10%이면 +1 | fundamental_score |
| `analyst_recommendation` | ≤2.0이면 +2 | fundamental_score |
| `vix_close` / `market_regime` | bear 레짐 -2, VIX>35 -1 | risk_score |
| `fcf_yield` | >0이면 +2 | fundamental_score |
| `roic_approx` | >15%이면 +2 | fundamental_score |
| `bb_position` | >0.95이면 -1 | risk_score |
| `ret_252d` | >0이면 +2 | momentum_score |
| `price_vs_ma200` | >1.0이면 +2 | momentum_score |

**매크로 레짐 연동** (2026-05-17 추가):
- `feature.us_macro_daily`에서 최신 `market_regime` / `vix_close` 조회 (`fetch_latest_macro_snapshot`)
- Bear 레짐: risk_score -2 + `bear_market_regime` 태그
- VIX > 35: risk_score -1 + `vix_extreme` 태그
- Bull 레짐: `bull_market_regime` 태그 (패널티 없음)
- 검증: `2026-05-15 market_regime=bull vix=18.4` — 정상 확인

**작업 파일**: `python/us/calculate_us_stock_rule_scores.py`, `python/us/us_db.py`
