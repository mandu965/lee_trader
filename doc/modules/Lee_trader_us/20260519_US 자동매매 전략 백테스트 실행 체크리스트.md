# US 자동매매 전략 백테스트 실행 체크리스트

*작성: 2026-05-19 | 목적: `US 자동매매 전략 백테스트 명세서`를 실제 실행 단계로 분해한 체크리스트*

---

## 1. 목표

이 체크리스트의 목표는 아래 한 가지입니다.

`현재 US 자동매매 운영 전략을 과거 구간에 그대로 재현하는 실전형 백테스트를 실행 가능한 상태로 만드는 것`

즉 단순 랭킹 테스트가 아니라:

- 후보선정
- 차단
- 주문 생성
- 체결
- 보유
- 매도
- 손익 집계

전 과정을 실제 운영 규칙과 맞추는 것이 목표입니다.

---

## 2. 선행 기준

백테스트 실행 전에 아래 3가지는 반드시 고정되어야 합니다.

### 2-1. 현재 운영 규칙 확정

확정 대상:

- 진입 대상 universe
- rank / grade 기준
- 매수 차단 규칙
- 종목당 비중 상한
- 총 포지션 수 상한
- 보유기간 규칙
- 매도 규칙

완료 기준:

- “현재 운영 전략은 무엇인가”를 문장으로 설명할 수 있음

### 2-2. point-in-time 데이터 기준 확정

확정 대상:

- 어떤 테이블/파일을 신호 입력으로 쓸 것인가
- 어떤 시점의 가격을 entry/exit에 쓸 것인가
- 미래 데이터 누출이 없는가

완료 기준:

- 거래일 `t`에 `t 이후 정보`를 읽지 않음

### 2-3. paper 운영 기준 확정

확정 대상:

- 주문 수량 계산
- 정수 수량 처리
- 현금 차감 방식
- 체결 가정

완료 기준:

- paper 운영과 백테스트가 다른 부분을 목록으로 설명할 수 있음

---

## 3. 작업 체크리스트

### Step 1. 전략 문장화

해야 할 일:

- 현재 US 자동매매의 진입 규칙 문장화
- 현재 차단 규칙 문장화
- 현재 청산 규칙 문장화

확인 질문:

- 어떤 종목이 사는 대상인가
- 어떤 종목이 차단되는가
- 언제 파는가

완료 기준:

- 전략 설명서 1장으로 정리 가능

---

### Step 2. 입력 데이터 소스 고정

해야 할 일:

- 랭킹/점수 입력 테이블 확정
- 가격 입력 테이블 확정
- benchmark 입력 확정
- sector / universe 메타데이터 확정

확인 질문:

- 이 데이터가 당시 시점에 존재하던 값인가
- 나중에 덮어쓴 값은 아닌가

완료 기준:

- 백테스트 입력 데이터 소스 목록 확정

---

### Step 3. 후보선정 단계 재현

해야 할 일:

- 거래일별 후보선정 규칙 재현
- rank / grade / score 조건 적용

확인 질문:

- 운영 화면에서 보이는 매수 후보와 같은 철학인가
- 단순 Top-N 추출로 단순화되지 않았는가

완료 기준:

- 거래일별 buy candidate 목록 생성 가능

---

### Step 4. 매수 차단 단계 재현

해야 할 일:

- 현금 부족 차단
- 중복 보유 차단
- 포지션 수 초과 차단
- 비중 상한 차단
- gap risk 차단
- risk penalty 차단

확인 질문:

- 실제 운영에서 막히는 종목이 백테스트에서도 막히는가

완료 기준:

- 거래일별 `ALLOW / BLOCK` 판정 가능

---

### Step 5. 주문 초안 생성 재현

해야 할 일:

- 주문 수량 계산
- 예정 금액 계산
- 정수 수량 처리

확인 질문:

- 실운영 paper 주문 수량과 같은 방식인가

완료 기준:

- 거래일별 order draft 생성 가능

---

### Step 6. 체결 시뮬레이션 기준 확정

해야 할 일:

- entry 가격 기준 고정
- exit 가격 기준 고정
- 미체결 처리 규칙 고정
- 슬리피지 가정 고정

확인 질문:

- 너무 낙관적인 체결 가정은 아닌가
- paper 체결 규칙과 철학이 같은가

완료 기준:

- entry/exit 체결 방식이 문장과 숫자로 명확함

---

### Step 7. 포지션 상태 관리 재현

해야 할 일:

- 평균단가 반영
- 보유수량 반영
- 보유일 계산
- 손익 계산
- 현금 업데이트

확인 질문:

- 거래 후 포지션 상태가 실제 운영과 같은가

완료 기준:

- 거래일별 포지션 스냅샷 생성 가능

---

### Step 8. 매도 규칙 재현

해야 할 일:

- 기간 만료 청산
- 손절/익절/트레일링 청산
- 리스크 상승 청산
- 점수 하락 청산

확인 질문:

- 진입 로직만 현재 기준이고 청산은 단순화돼 있지 않은가

완료 기준:

- 거래일별 sell decision 생성 가능

---

### Step 9. 비용 반영

해야 할 일:

- 수수료 반영
- 슬리피지 반영
- 스프레드 반영

확인 질문:

- gross와 net이 구분되는가

완료 기준:

- 비용 반영 전/후 성과 모두 산출 가능

---

### Step 10. 자산곡선 생성

해야 할 일:

- 일별 equity 계산
- 현금 + 보유 평가금액 합산
- 일별 자산곡선 생성

확인 질문:

- 누적수익률과 MDD를 일별로 재현할 수 있는가

완료 기준:

- daily equity curve 산출 가능

---

### Step 11. 성과 요약

해야 할 일:

- 누적수익률
- MDD
- 승률
- 종목당 기대값
- 평균 보유일
- turnover
- benchmark 초과수익

확인 질문:

- 단순 총수익률 외에 리스크도 같이 보이는가

완료 기준:

- 전략 요약표 작성 가능

---

### Step 12. 비교 실험

해야 할 일:

- 현재 전략 그대로
- risk penalty 제거
- gap risk 차단 제거
- 단순 보유기간 청산 버전

확인 질문:

- 어떤 규칙이 실제 성과를 만들고 있는가

완료 기준:

- 기준 전략 vs 변형 전략 비교 가능

## 5. 검증 체크리스트

결과가 나와도 아래 검증을 반드시 해야 합니다.

### 검증 1. 실운영 일치성

- 동일 날짜에 운영 의사결정과 백테스트 의사결정이 비슷한가

### 검증 2. 체결 일치성

- paper 체결 규칙과 백테스트 체결 가정이 과도하게 다르지 않은가

### 검증 3. 손익 계산 일치성

- 포지션/현금/평가금액 계산이 paper 운영과 같은가

### 검증 4. benchmark 비교 가능성

- SPY / QQQ와 같은 기준으로 비교 가능한가

### 검증 5. 해석 가능성

- “왜 벌었는가 / 왜 잃었는가”를 규칙 수준으로 설명할 수 있는가

2. 최소 수개월 이상 결과 생성
3. gross / net 성과 구분
4. benchmark 비교 가능
5. 거래 내역과 자산곡선 확보
6. 규칙별 기여도 비교 가능

## 7. 회의용 우선순위

가장 먼저 해야 할 순서는 아래입니다.

1. 현재 운영 규칙 문장화
2. 입력 데이터 point-in-time 기준 확정
3. 체결 규칙 고정
4. 차단 규칙 재현
5. 자산곡선/성과 집계
6. 비교 실험

즉 실행 순서의 핵심은:

`신호 -> 체결 -> 포지션 -> 손익` 흐름을 운영과 같게 맞추는 것입니다.
