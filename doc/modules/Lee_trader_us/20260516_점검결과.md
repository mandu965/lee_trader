## 3. 랭킹 공식 (rule_v1) 상세

### 총점 계산식

```
total_score = momentum_score     (0 ~ 25점)
            + rs_score           (0 ~ 20점)
            + fundamental_score  (0 ~ 20점)
            + growth_score       (0 ~ 15점)
            + valuation_score    (0 ~ 10점)
            + risk_score         (-10 ~ 0점)
─────────────────────────────────────────
max = 90점   (risk 패널티 없을 때)
min = -10점  (모든 항목 최저)
```

---

### ① 모멘텀 (0 ~ 25점)

| 조건 | 배점 |
|---|---|
| 20일 수익률 양수 | +5점 |
| 60일 수익률 양수 | +5점 |
| 가격 > 20일 MA | +5점 |
| 가격 > 60일 MA | +5점 |
| 두 이평 모두 상회 | +5점 보너스 |

**사용 데이터**: `ret_20d`, `ret_60d`, `ma_20`, `ma_60` (feature.us_stock_technical_feature)

---

### ② 상대강도 (0 ~ 20점)

| 조건 | 배점 |
|---|---|
| SPY 대비 20일 초과수익 > 0 | +5점 |
| SPY 대비 60일 초과수익 > 0 | +5점 |
| QQQ 대비 20일 초과수익 > 0 | +5점 |
| QQQ 대비 60일 초과수익 > 0 | +5점 |

**사용 데이터**: `rs_spy_20d`, `rs_spy_60d`, `rs_qqq_20d`, `rs_qqq_60d`
(feature.us_stock_relative_strength_daily — SPY/QQQ 대비 수익률 차이)

---

### ③ 펀더멘털 (0 ~ 20점)

| 지표 | 조건 | 배점 |
|---|---|---|
| ROE (자기자본이익률) | ≥ 15% | +5점 |
| 영업이익률 (operating_margin) | ≥ 15% | +5점 |
| 순이익률 (profit_margin) | 양수 | +5점 |
| 부채비율 (D/E) | ≤ 0.5 | +5점 / 0.5~1.0 | +3점 / 1.0~2.0 | +1점 |

**사용 데이터**: `feature.us_stock_financial_feature` (ROE, 마진, 부채비율)

---

### ④ 성장성 (0 ~ 15점)

| 지표 | 조건 | 배점 |
|---|---|---|
| 매출 성장률 YoY | > 10% | +5점 / > 20% | +2점 추가 |
| 이익 성장률 YoY | > 10% | +5점 |
| 매출·이익 동반 성장 | 둘 다 양수 | +3점 보너스 |

**사용 데이터**: `revenue_growth_yoy`, `earnings_growth` (재무 피처)
> 현재 `revenue_growth_yoy` null 비율 69% — yfinance 분기 데이터 제한으로 YoY 계산이 안 되는 경우 있음

---

### ⑤ 밸류에이션 (0 ~ 10점)

| 지표 | 조건 | 배점 |
|---|---|---|
| Trailing PER | 0 < PER ≤ 20 | +5점 |
| Forward PER | 0 < PER ≤ 25 | +5점 |

**현재 상태**: Forward PER은 yfinance에서 수집되지 않아 현재 0점. Trailing PER도 수집률이 낮아 valuation_score 대부분 0점.

---

### ⑥ 리스크 패널티 (−10 ~ 0점)

| 조건 | 패널티 |
|---|---|
| 20일 변동성 과도 | −2 ~ −5점 |
| 거래량 급감 | −2점 |
| 데이터 품질 불량 | −3점 |

---

### 등급 기준

| 등급 | 점수 | 의미 |
|---|---|---|
| **STRONG_BUY** | ≥ 80점 | 모든 요소 강점, 즉시 매수 후보 |
| **BUY** | 70 ~ 79점 | 우량 매수 후보 |
| **WATCH** | 60 ~ 69점 | 관찰 대기 |
| **HOLD** | 50 ~ 59점 | 보유 유지 |
| **EXCLUDE** | < 50점 | 제외 |

## 4. 자동화 스케줄러

### 일간 실행 시간

```
매일 06:30 KST
= 17:30 ET (미국 동부 여름시간 / 서머타임)
= 18:30 ET (미국 동부 겨울시간)
```

미국 장 마감(16:00 ET) 후 1.5~2.5시간 뒤 실행 → yfinance에 당일 종가 반영 충분.

### 파이프라인 실행 순서 (`scripts/run_us_daily_pipeline.ps1`)

```
Step 1: run_us_daily_pipeline.py --mode incremental
         ├── Universe 갱신 (CSV → DB)
         ├── 가격 incremental 수집 (마지막 날짜 이후만)
         ├── 품질 검증 (stale, missing)
         └── 기술적 피처 빌드

Step 2: build_us_relative_strength_features.py
         └── SPY/QQQ 대비 상대강도 재계산 (전체 히스토리)

Step 3: calculate_us_stock_rule_scores.py --trade-date $(TODAY)
         └── rule_v1 점수 계산 → recommend.us_stock_rank_daily

로그 저장: logs/scheduler/us/us_daily_YYYYMMDD_HHmmss.log
```

### Task Scheduler 등록 (관리자 PowerShell에서 1회 실행)

```powershell
powershell -ExecutionPolicy Bypass -File "D:\ai\lee_trader\scripts\register_us_daily_task.ps1"
```

수동 실행 테스트:

```powershell
powershell -ExecutionPolicy Bypass -File "D:\ai\lee_trader\scripts\run_us_daily_pipeline.ps1"
```

## 5. 종목 선정 기준

### 유니버스

- **현재**: NASDAQ100 (103 tickers — 101개 종목 + SPY + QQQ 벤치마크)
- **CSV 위치**: `data/us/nasdaq100_universe.csv`
- SPY / QQQ는 벤치마크 용도로만 수집 — 랭킹 대상에서 ETF 제외 (`is_etf` 필터)

### BUY 후보 필터 조건 (Shadow 모드 기준)

| 조건 | 기준 |
|---|---|
| 최소 등급 | BUY 이상 (70점+) |
| 데이터 상태 | `data_status = READY` |
| ETF 제외 | `is_etf = false` |
| 갭 업 제한 | 당일 갭 ≤ 5% |
| 일중 변동 | ≤ 8% |
| Cooldown | 매수 후 10 영업일 재매수 금지 |
| 재무 데이터 | 최소 1건 이상 존재 |
| 상대강도 | SPY 또는 QQQ 대비 20일 초과수익 양수 권장 |

## 8. 라이브 전환 요건 (Shadow → Paper → Live)

### Shadow 모드 (현재)

- 실제 주문 없이 의사결정 로그만 기록
- **최소 20 영업일** Shadow 운영 필요 → Paper 전환 가능

### Paper Trading (20 영업일 후, ~2026-06-13)

```
.env 변경:
US_BUY_AUTOMATION_MODE=PAPER
US_PAPER_TRADING_ENABLED=1
```

- 가상 포지션 진입/청산 시뮬레이션
- **60일 Paper 운영 후** Live 요건 평가

### Live 전환 요건 (자동 평가, `live_readiness_evaluator.py`)

| 요건 | 기준 | 예상 달성 시점 |
|---|---|---|
| Shadow 운영 일수 | ≥ 20일 | 2026-06-13 |
| Paper 운영 일수 | ≥ 60일 | 2026-08-12 |
| Paper 주문 건수 | ≥ 20건 | 2026-08-12 전후 |
| Win Rate | ≥ 50% | Paper 결과 의존 |
| Max Drawdown | ≤ 15% | Paper 결과 의존 |
| SPY 초과수익 | > 0% | Paper 결과 의존 |
| 브로커 API 연결 | 필수 | 별도 브로커 선정 필요 |

> **Live 자동 전환 불가**: `live_implemented=False` 하드코딩 + 수동 승인 필수

## 9. 알려진 데이터 한계 및 보완 계획

| 항목 | 현황 | 보완 방안 |
