## 2단계 — KIS 해외 API Smoke Test

계좌 정보 입력 후, 실제 주문이 나가지 않도록 지정가 $1.00으로 테스트 후 즉시 취소.

```bash
cd d:\ai\lee_trader
.venv\Scripts\python.exe -c "
from brokers.us.kis_overseas_client import KisOverseasOrderClient
c = KisOverseasOrderClient()

# 1. 주문 제출 (AAPL, limit $1 → 체결 안 됨)
r = c.submit_order({'side': 'BUY', 'symbol': 'AAPL', 'limit_price': 1.0, 'order_qty': 1})
print('submit:', r)

# 2. 상태 조회
if r.get('broker_order_id'):
    s = c.get_order_status(r['broker_order_id'])
    print('status:', s)

    # 3. 취소
    cancel = c.cancel_order(r['broker_order_id'])
    print('cancel:', cancel)
"
```

**확인 포인트:**
- `submit` 결과에 `broker_order_id` 형식이 `AAPL:XXXXXXX`로 반환되는지
- `status` 결과가 조회 가능하며 주문 접수 상태(`OPEN`/`PENDING`/동등 상태 포함)로 해석 가능한지
- `cancel` 결과가 즉시 최종 상태가 아니더라도, 취소 요청 성공 후 최종 미체결 종료 상태까지 추적 가능한지

**판정 원칙:**
- 상태 문자열 exact match가 아니라, 주문 ID 생성 / 상태 조회 가능 / 취소 후 종료 상태 확인 가능 여부를 기준으로 판정
- 브로커 응답 상태명이 다르더라도 의미가 동일하면 통과로 간주

## 3단계 — 게이트 순차 활성화

Smoke Test 통과 후 `.env`를 아래 순서로 단계적으로 변경.  
**한 단계씩 실거래 확인 후 다음 단계로 이동.**

### Step 1 — 한도/세부 플래그 먼저 설정

```env
US_LIVE_MAX_ORDER_AMOUNT_USD=500      # 건당 최대 $500
US_LIVE_MAX_DAILY_ORDER_COUNT=5
US_LIVE_MAX_DAILY_NEW_BUYS=2
US_LIVE_BUY_ENABLED=true
US_LIVE_SELL_ENABLED=true
```

### Step 2 — Live 거래 플래그 활성화

```env
US_LIVE_TRADING_ENABLED=true
US_LIVE_ORDER_ENABLED=true
```

### Step 3 — 마지막에 실주문 차단 해제

```env
US_MICRO_REAL_ORDER_BLOCKED=false
US_MICRO_ALLOW_LIVE=true
```

**각 Step 공통 확인사항:**
- [ ] 환경변수 변경 후 관련 컨테이너/스케줄러 재기동 또는 반영 확인
- [ ] dry-run, preview, 또는 직전 로그에서 한도/enable 값이 기대대로 로드되는지 확인
- [ ] 긴급 차단값(`US_MICRO_REAL_ORDER_BLOCKED=true`, `US_LIVE_TRADING_ENABLED=false`)을 바로 되돌릴 수 있게 기록
