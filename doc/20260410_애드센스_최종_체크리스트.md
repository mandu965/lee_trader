## 3. 신청 전 반드시 남은 항목

### 3.1 실제 도메인 기준 URL 반영

현재 로컬 확인 기준에서는 `robots.txt`, `sitemap.xml`이 `http://localhost:3000` 기준으로 노출된다.

실제 신청 전 반드시 아래 중 하나로 반영해야 한다.

- `SITE_BASE_URL=https://www.leetraderlab.com`
- 또는 실제 운영 도메인

관련 위치:

- [node/index.js](d:/ai/Lee_trader/node/index.js)
- [.env.render.example](d:/ai/Lee_trader/.env.render.example)
- [render.yaml](d:/ai/Lee_trader/render.yaml)

확인해야 할 최종 주소:

- `https://www.leetraderlab.com/robots.txt`
- `https://www.leetraderlab.com/sitemap.xml`
- `https://www.leetraderlab.com/ads.txt`

### 3.2 실제 메일 수신 확인

현재 정책 페이지에는 `mandu965@naver.com`이 반영되어 있다.

신청 전 아래를 실제로 점검해야 한다.

- 외부에서 메일 발송 시 수신되는지
- 회신 가능 상태인지
- 스팸함으로 빠지지 않는지

### 3.3 애드센스 코드 삽입

현재는 정책/문맥/ads.txt 정리 단계까지 완료한 상태다.

신청 직전에는 AdSense에서 제공하는 사이트용 코드가 실제 공개 페이지 `<head>`에 들어가야 한다.

삽입 후보 파일:

- [node/public/landing.html](d:/ai/Lee_trader/node/public/landing.html)
- [node/public/about.html](d:/ai/Lee_trader/node/public/about.html)
- [node/public/methodology.html](d:/ai/Lee_trader/node/public/methodology.html)
- [node/public/contact.html](d:/ai/Lee_trader/node/public/contact.html)
- [node/public/privacy.html](d:/ai/Lee_trader/node/public/privacy.html)
- [node/public/terms.html](d:/ai/Lee_trader/node/public/terms.html)
- [node/public/disclaimer.html](d:/ai/Lee_trader/node/public/disclaimer.html)
- 필요 시 콘텐츠 상세/목록 페이지도 동일 반영

## 4. 권장 최종 점검 순서

1. 실제 운영 도메인을 확정한다.
2. `SITE_BASE_URL`을 실제 도메인으로 반영한다.
3. 배포 후 `robots.txt`, `sitemap.xml`, `ads.txt`를 실제 도메인에서 확인한다.
4. 문의 메일 수신 테스트를 한다.
5. AdSense 사이트 코드를 `<head>`에 삽입한다.
6. Search Console 색인 상태와 주요 페이지 접근을 확인한다.
7. 애드센스 신청을 진행한다.

## 5. 현재 판단

현재 상태는 "정책 페이지와 공개 문맥 정리는 완료, 실제 도메인 기준 최종 설정과 AdSense 코드 삽입만 남은 단계"다.

즉, 신청 직전 준비 단계로는 충분히 올라와 있지만, 실도메인 기준 URL 정합성과 실제 AdSense 코드 삽입 없이 바로 신청하는 것은 권장하지 않는다.
