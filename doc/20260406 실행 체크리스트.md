## 2. 현재 운영 해석

- 파이프라인 자체는 정상 수행됨
- 현재 운영 결과는 보수 판정 상태
- `READINESS 60D = WAIT`
- `BUY GATE = BLOCK`
- `walkforward_acceptance = REJECTED`

현재 `REJECTED`는 스크립트 실패가 아니라 실제 판정 결과입니다.

주요 사유
- `ordering_not_stable`
- `drawdown_too_deep`
- `confidence_monotonicity_missing`
