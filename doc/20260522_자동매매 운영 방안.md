# KR 자동매매 운영 방안 (2026-05-22)

## 1. 목적

현재 시점에서 가장 중요한 것은 새 전략을 늘리는 것이 아니라,  
**KR 자동매매를 더 안정적이고 더 수익성 있게 운영할 수 있는 운영 구조를 정리하는 것**이다.

지금 KR 자동매매는 이미 실운영 경로에 올라와 있지만, 아래 질문들은 아직 충분히 정리되지 않았다.

- 현재 `09:30` 1회 매매가 최선인가
- 장중 추가 점검이 필요한가
- 매수와 매도를 같은 빈도로 볼 필요가 있는가
- 종가 기준 선정 종목을 장중에 다시 걸러야 하는가
- 장초반 변동성, 갭 상승, 시장 급변에 어떻게 대응할 것인가

이 문서는 위 질문들에 대해 회의할 때 기준이 되는 운영 방안 초안이다.

---

## 2. 현재 구조 요약

현재 KR 자동매매는 대체로 아래 구조로 이해할 수 있다.

1. 종가 기준으로 후보 종목 선정
2. 익일 장중 정해진 시점에 주문 실행
3. 보유 중 포지션은 별도 risk / holding / replace 정책으로 관리

현재 논의의 핵심은 종목 선정 모델 자체보다,  
**운영 시점과 실행 규칙이 실제 수익을 얼마나 깎고 있는지**를 다시 보는 것이다.

## 3. 지금 회의가 필요한 이유

### 3-1. 모델보다 운영 방식이 성과를 깎을 수 있음

좋은 종목을 골라도 운영 방식이 맞지 않으면 성과가 크게 훼손된다.

예를 들면:

- 장초반 너무 이른 시점에 진입
- 갭 급등 종목을 그대로 추격 매수
- 시장이 약한데도 정해진 시각에 기계적으로 진입
- 신규 진입은 잦은데 장중 약화 신호는 충분히 반영하지 못함

즉, **종목 선정 엔진**과 **운영 실행 엔진**을 분리해서 봐야 한다.

### 3-2. 지금은 KR에 집중할 시점

현재 운영 원칙상 KR 자동매매가 주력이다.  
따라서 지금 필요한 회의는 “전략을 더 늘릴까?”가 아니라,

**“KR 자동매매를 어떤 운영 리듬으로 돌려야 가장 실전적이냐”** 이다.

## 4. 핵심 의사결정 주제

회의는 아래 4개 축으로 나눠서 보는 것이 좋다.

### 4-1. 언제 매수할 것인가

현재 질문:

- `09:30` 1회만 매수할지
- `09:30 + 장중 추가 점검` 구조로 갈지
- 장초반 변동성을 피하기 위해 진입 시점을 늦출지
- 장중 추가 점검이 있어도 신규 매수는 오전 1회만 허용할지

검토 포인트:

- 장초반 호가 왜곡이 큰지
- `09:30` 진입이 평균적으로 불리한지
- `10:00` 또는 `10:30` 진입이 더 안정적인지
- 장중 다회 매수가 과매매로 이어질 위험은 없는지

### 4-2. 장중에 무엇을 다시 볼 것인가

종가 기준으로 뽑은 종목을 장중에 다시 체크할 필요가 있는지 판단해야 한다.

후보 체크 항목:

- 갭 상승 폭
- 갭 하락 폭
- 장중 변동성 급증 여부
- 거래대금 / 유동성 급감 여부
- 시장 전체 defensive 전환 여부
- 기존 보유 종목의 약화 신호

핵심은 장중에 “새 종목을 다시 뽑는 것”이 아니라,  
**종가 기준 선정 종목을 실제 매수 가능한 상태인지 재검증하는 것**이다.

### 4-3. 매수와 매도를 같은 방식으로 볼 것인가

매수와 매도는 운영 철학이 달라야 할 수 있다.

- 매수: 신중해야 함
- 매도: 더 자주 봐야 할 수 있음

따라서 아래 구조를 검토할 필요가 있다.

- 매수는 오전 1회 또는 2회 제한
- 매도 / 보유 점검은 더 자주 수행
- 장중 추가 체크는 신규 매수 확대보다 리스크 감시 중심

### 4-4. 무엇이 실제 수익을 깎고 있는가

회의에서 반드시 숫자로 확인해야 할 질문:

- 너무 이른 진입이 문제인가
- 좋은 종목을 너무 빨리 교체하는가
- 장초반 갭 과열 종목 진입이 손실 원인인가
- 시장 약세 구간에서 자동 진입이 과한가
- 종가 선정은 괜찮은데 실행 시점이 안 좋은가

## 5. 운영 대안 초안

### 안 A — 현재 구조 유지

- 종가 기준 종목 선정
- 익일 `09:30` 1회 매수
- 장중 신규 매수 없음
- 보유 / 매도는 기존 정책 유지

장점:

- 단순함
- 운영 추적 쉬움
- 과매매 가능성 낮음

단점:

- 장초반 변동성에 그대로 노출
- 갭 과열 종목 필터링 부족 가능
- 진입 품질 개선 여지 제한

### 안 B — 오전 2단계 진입 구조

- 종가 기준 종목 선정
- `09:30` 1차 점검
- `10:00~10:30` 2차 실행 또는 대체 실행
- 장중 신규 매수는 오전까지만 허용

장점:

- 장초반 왜곡 완화 가능
- 갭 과열 종목 필터링 여지 증가
- 동일 신호를 더 현실적으로 집행 가능

단점:

- 운영 복잡도 증가
- 로직이 애매하면 오히려 일관성 저하

### 안 C — 종가 선정 + 장중 재검증 구조

- 종목 선정은 종가 기준 고정
- 익일 장중에는 매수 전 재검증만 수행
- 예: 갭, 시장 상태, 유동성, 변동성 기준 확인
- 조건 미충족 시 그날 매수 스킵

장점:

- 선정 모델과 실행 모델 분리 가능
- 불리한 진입을 줄일 수 있음
- 장중 재선정 없이도 실전성 강화 가능

단점:

- 어떤 조건으로 스킵할지 설계 필요
- 지나치게 보수적이면 체결 기회 감소

### 안 D — 매수는 제한, 장중은 리스크 감시 중심

- 종가 선정
- 오전 한정 매수
- 장중에는 신규 진입보다 기존 포지션 리스크 점검
- 시장 급변 / 종목 급락 / 방어 레짐 전환 감시 강화

장점:

- 과매매 억제
- 운영 철학 명확
- KR 주력 운영에 맞는 현실적 구조

단점:

- 공격적인 추가 기회 포착은 약함

## 6. 현재 가설 초안

현 시점에서 우선 검토할 만한 방향은 아래다.  
단, 아래 내용은 확정안이 아니라 회의를 위한 **가설 초안**이다.

### 우선 검토 운영 원칙

1. **종목 선정은 종가 기준 유지**
2. **매수 실행은 장초반 1회 또는 2회로 제한**
3. **장중에는 신규 매수 확대보다 리스크 체크 중심**
4. **매도/보유 점검 빈도는 매수보다 더 높게 검토**
5. **장중 다회 매매 전략으로 가기 전에 먼저 `09:30` 진입 품질을 계량 검증**

즉, 바로 장중 자동매매를 늘리기보다,

**현재 `09:30` 진입이 실제로 좋은지부터 검증한 뒤 필요한 범위만 추가하는 방식**이 적절하다.

## 7. 회의 안건 제안

### 안건 1. 현재 `09:30` 단일 진입 평가

- 최근 진입 종목 기준 수익/손실 패턴
- 장초반 진입의 장단점
- `09:30`이 너무 빠른지 여부

### 안건 2. 장중 재검증 필요 여부

- 갭 과열 종목을 스킵해야 하는가
- 시장 방어 레짐 전환 시 매수 중단할 것인가
- 변동성 급등 시 당일 진입을 보류할 것인가

### 안건 3. 매수/매도 점검 빈도 분리 여부

- 매수는 하루 1회 또는 2회 제한
- 매도 / 보유는 장중 추가 점검 가능
- 리스크 이벤트는 즉시 반응할 것인가

### 안건 4. 장중 체크 항목 후보 확정

- 갭
- 거래대금
- 변동성
- 시장 상태
- 보유 종목 약화 신호

### 안건 5. 실험 우선순위 결정

- `09:30` 유지 vs `10:00` 지연 비교
- 갭 필터 추가 여부
- 오전 2회 점검 도입 여부
- 장중 리스크 감시 강화 여부

### 안건 6. 보유/교체/청산 운영 리듬 재검토

- 진입 후 교체 유예를 장중에도 일관되게 유지할 것인가
- 장중 약화 신호를 `즉시 청산`, `축소`, `관찰` 중 어디까지 반영할 것인가
- 보유 종목은 매수 후보보다 더 자주 점검해야 하는가
- 장중 점검의 목적이 `신규 매수 확대`인지 `기존 포지션 보호`인지 명확히 할 것인가

## 8. 비교 지표 / 판정 기준

회의가 추상적으로 끝나지 않도록, 운영안 비교 시 아래 지표를 함께 본다.

### 8-1. 매수 시점 비교 지표

- 체결 기준 가격 불리도
- 시가 대비 진입 시점 가격 차이
- 당일 종가 기준 손익
- 3거래일 / 5거래일 후 수익률
- 미체결 또는 스킵 비율
- 갭 과열 종목 회피 비율

### 8-2. 운영 품질 지표

- 신규 매수 횟수
- 보유 종목 교체 횟수
- 장중 점검으로 인한 스킵 횟수
- 장중 경고 후 실제 손실 회피 사례 수
- 운영 복잡도 증가 여부

### 8-3. 보유/청산 관련 지표

- 진입 후 평균 보유기간
- 진입 후 5영업일 이내 교체 비율
- 장중 약화 신호 발생 후 실제 성과
- 조기 청산 후 재상승 놓침 비율
- 기존 대비 `winner hold / loser cut` 품질 개선 여부

### 8-4. 최종 판정 기준

운영안은 아래 4개 중 최소 2~3개 이상에서 개선이 확인될 때만 다음 단계로 올린다.

- 진입 품질 개선
- 불필요한 과매수 감소
- 조기 교체 / 조기 청산 감소
- 운영 복잡도 증가 대비 성과 개선 존재

## 9. 권장 실험 순서

운영 변경은 한 번에 많이 넣지 않는 것이 중요하다.

### 1단계

- 현재 `09:30` 진입 품질 점검
- 최근 진입 사례 복기
- 장초반 진입이 불리한지 정성/정량 확인
- 보유 종목의 장중 약화 사례도 함께 복기

### 2단계

- 가장 단순한 추가 필터 1개만 도입 검토
- 예: 갭 과열 스킵
- 동시에 `장중 약화 신호는 관찰만 할지, 감액까지 할지` 정책 초안 마련

### 3단계

- 필요 시 `09:30 + 10:00~10:30` 이중 점검 검토
- 단, 신규 매수 횟수는 제한 유지
- 보유 종목 점검 빈도와 신규 매수 점검 빈도를 분리할지 검토

### 4단계

- 장중 리스크 감시 자동화 강화
- 신규 매수보다 보유 종목 관리 품질 개선 우선

## 10. 회의 목표

이번 회의의 목표는 아래 둘 중 무엇을 할지 명확히 정하는 것이다.

1. 운영 원칙만 합의하고 추가 데이터 수집부터 할 것인지
2. 바로 작은 실험 1개를 선정해서 검증에 들어갈 것인지

권장 방식은 아래다.

- 먼저 운영 원칙의 범위를 좁힌다
- 그 다음 가장 단순한 실험 1개만 선정한다
- 결과가 확인되면 다음 변경으로 넘어간다

## 11. 결론

지금 KR 자동매매에서 필요한 것은 “더 자주 매매하는 시스템”이 아니라,

**더 좋은 시점에 진입하고, 더 나쁜 상황을 피하고, 더 일관되게 운영하는 시스템**이다.

따라서 회의의 목표는 아래처럼 잡는 것이 맞다.

- `09:30`이 맞는지 검증
- 장중 체크가 필요한지 판단
- 매수와 매도의 운영 리듬을 분리할지 결정
- 최소 변경으로 가장 큰 운영 개선 효과를 내는 순서를 정리

한 줄로 정리하면:

> **지금 KR 자동매매에서 필요한 것은 전략 추가가 아니라 운영 정교화다.**

## 12. 전문가 의견 반영안 (2026-05-22 추가)

### 12-1. 핵심 진단

현재 KR 자동매매의 가장 큰 구조적 문제는 아래 갭이다.

- 모델 신호 기준: 전일 종가
- 실제 집행 기준: 익일 `09:30` 시가 부근

즉, 모델이 전일 종가 기준으로 기대수익이 높다고 판단한 종목이라도,
익일 장초반에 이미 크게 갭 상승한 상태라면 기대수익의 상당 부분이 미리 소진될 수 있다.

예시:

- 전일 종가 10,000원에서 모델이 `30일 후 +8% 기대`로 선정
- 익일 장초반 시가가 이미 +5% 상승한 10,500원
- 이 경우 기대수익의 절반 이상이 선반영되어 실제 집행 수익률은 크게 낮아질 수 있음

결론적으로,  
**현재는 `09:30`이라는 시간 자체보다 "전일 종가 신호를 익일 갭이 훼손하는 문제"를 먼저 막는 것이 더 중요하다.**

---

### 12-2. 수익률 관점 우선순위

#### 1순위 — 갭 필터 도입

장초반 시가 기준 갭 상승 폭이 일정 수준 이상이면 당일 매수를 스킵한다.

- 기본 가설: `+5% 이상 갭 상승 시 스킵`
- 이유:
  - 모델은 종가 대비 기대수익을 전제로 작동
  - 갭이 클수록 기대수익이 이미 선취됨
  - 모델은 맞아도 실제 수익률은 크게 줄어들 수 있음

주의:

- 강한 모멘텀 종목 일부를 놓칠 수 있음
- 그러나 현 단계에서는 `기대수익이 많이 소진된 상태로 추격 매수`하는 리스크를 줄이는 편이 더 중요함

#### 2순위 — 보유종목 장중 급락 알림

보유 종목이 장중 일정 수준 이상 급락하면 자동 매도 대신 **알림만** 보낸다.

- 예시 기준: 당일 `-5% 이상` 하락 시 텔레그램 알림
- 이유:
  - 모델은 30일 예측 기반이므로 장중 급락 이벤트에는 둔감할 수 있음
  - 그렇다고 장중 자동 손절을 넣으면 모델 보유 철학과 충돌할 수 있음

현재 권장 구조:

- 장중 급락 → 자동 매도 아님
- 장중 급락 → 경고 알림 발송
- 최종 대응은 사람이 판단

#### 3순위 — 진입 시간 변경은 보류

`09:30 → 09:40~10:00` 지연 진입은 아이디어로는 가능하지만, 효과는 아직 불확실하다.

현재 판단:

- 갭 필터를 먼저 넣으면 시간 변경의 추가 효과는 제한적일 수 있음
- 따라서 시간 변경은 1순위가 아니라, 갭 필터 적용 후 데이터 확인 뒤 판단하는 것이 맞음

### 12-3. 반드시 하지 말아야 할 것

| 항목 | 이유 |
|---|---|
| 장중 자동 손절 | 30일 예측 모델과 충돌 가능성 높음 |
| 오후 신규 자동 매수 추가 | 감시 복잡도 증가 대비 수익 개선 불확실 |
| 장중 신규 종목 재선정 | 현재 모델은 전일 종가 기준 학습 구조 |

### 12-4. 제안 운영 구조

현재 구조:

```text
종가 선정 → 익일 09:30 일괄 매수
```

제안 구조:

```text
종가 선정
→ 익일 장시작 후 갭 확인 (이미 자동 적용 중)
→ 갭 +3% 이상: 매수 차단 (소프트)
→ 갭 +5% 이상: 매수 차단 (하드)
→ 갭 정상: 기존 타이밍대로 매수
→ 장중 보유 종목 확인: 운영자 수동 모니터링
```

핵심은 아래다.

- 시간 변경보다 `사전 차단 레이어` 추가가 먼저
- 장중 체크의 목적은 `신규 매수 확대`가 아니라 `불리한 진입 회피`
- 갭 필터는 이미 구현·작동 중이므로 신규 개발 불필요

### 12-5. 회의 결론 (2026-05-22 확정)

코드 검토 및 회의 결과로 아래 사항이 확인·결정됐다.

**확인된 사항**

| 항목 | 결과 |
|---|---|
| 갭 상승 매수 차단 | 이미 구현 및 실환경 작동 확인 (`ENTRY_GAP_BLOCK_UP_PCT=0.03`, `ENTRY_GAP_HARD_BLOCK_UP_PCT=0.05`) |
| 갭 하락 매수 차단 | 이미 구현 및 실환경 작동 확인 (`ENTRY_GAP_BLOCK_DOWN_PCT=-0.04`) |
| 장중 후보 재분류 코드 | `run_intraday_refresh.py` 존재, 스케줄 미연결 |

**결정된 사항**

| 항목 | 결정 |
|---|---|
| 갭 필터 임계값 조정 | 현재 기본값(+3%/+5%/-4%) 유지. 서버 데이터 확인 후 재검토 |
| 장중 텔레그램 알림 | 도입 안 함. 운영자가 직접 계좌 확인 |
| intraday refresh 스케줄 등록 | 보류. 알림 없으면 의미 제한적 |
| 수동 매도 | 원칙적으로 지양. 필요 시 마감 배치 통해 처리하여 이력 정합성 유지 |
| 오후 자동 매수 추가 | 도입 안 함 |

**지금 당장 수익률에 가장 직접적인 항목은 장중 운영이 아니다:**

```
1순위: BUY_ALLOWED 전환 (PILOT 수량 제한 해제)
2순위: 모델 재학습 (pred_return_30d, Calibration, Sample Weight 반영)
3순위: 보유기간 정합성 개선 (AI_MAX_HOLDING_DAYS=30 검토)
```

→ 세 항목 모두 서버 접속 후 즉시 실행 대상이다.
