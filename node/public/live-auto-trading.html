실자동매매 운영

실주문 엔진 자체를 여기서 돌리는 것이 아니라, 오늘의 intent, 주문 초안, 최근 제출 결과, 실계좌 보유 상태를 한 화면에서 보는 운영 보드입니다.

기본 흐름은 `16:00 종가 배치`, `12:00 장중 갱신`, `09:30 자동매수 사이클`입니다. 자동매수 스케줄러는 기본적으로 주문 초안까지 만들고, 명시적 env 스위치가 없으면 실주문을 실행하지 않습니다.

계좌 잔고 상세

예수금, 증권평가, 매입원가, 총자산, 현금비중을 실계좌 기준으로 확인합니다.

실행 상태 요약

gate, intent, 주문 초안이 서로 맞는지 먼저 확인합니다.

운영 메모

자동매매 화면에서 가장 먼저 봐야 할 포인트만 짧게 묶어둡니다.

실운영 해석

왜 신규 매수 후보가 안 보이는지, 현재 화면을 어떻게 읽어야 하는지 먼저 설명합니다.

WATCH 가정 시뮬레이션

실운영과 분리된 가정용 후보입니다. 여기 나온 종목은 그대로 주문되지 않습니다.

Trade Intents

전략 판단 결과입니다. 실제 주문 후보와 설명용 판단을 구분해서 봅니다.
상태 코드 종목명 판단유형 우선순위 목표비중 사유

Order Requests Preview

주문 초안 결과입니다. 차단되지 않은 항목만 실제 제출 후보로 넘어갑니다.
상태 요청ID 코드 종목명 매수/매도 Intent 요청수량 허용수량 차단사유 사유

Order Execution

가장 최근 실제 제출 결과입니다. 주문 시도 성공/실패와 차단 사유를 확인합니다.
상태 요청ID 코드 매수/매도 수량 주문번호 스킵/오류 사유

Scheduler Runtime

종가, 장중, 자동매수 스케줄러의 마지막 성공 시각과 현재 상태를 확인합니다.
스케줄러 상태 마지막 성공일 마지막 성공시각 최근 오류

실계좌 보유 상태

실계좌 보유 CSV 기준입니다. 주문 초안에서 `holding_qty_missing`가 뜨면 이 표와 먼저 맞춰야 합니다.
상태 코드 종목명 수량 평균단가 현재가 평가금액 손익 손익률 비중
