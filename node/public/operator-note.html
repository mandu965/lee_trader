Operator Note

관리자 말씀

공개 페이지를 보시는 분들이 혼동하기 쉬운 운영 기준을 먼저 분명하게 남겨두는 안내 페이지입니다.

핵심 안내

공개 화면의 매수, 매도 기능은 관리자 전용입니다. 일반 방문자는 기록과 해석을 보는 용도로 이해하시면 됩니다.

매수·매도 기능

매수, 매도 입력 기능은 관리자만 사용할 수 있습니다. 공개 화면에 버튼이 보이더라도 실제 실행 권한은 관리자 인증이 있어야만 열립니다.

보유종목과 매매이력

보유종목, 매매이력 화면은 실제 관리자가 기록한 운영 내역입니다. 자동으로 생성된 가상 기록이 아니라 운영 로그에 가깝게 보시면 됩니다.

현재 운영 상태

현재는 소액 테스트를 진행하고 있습니다. 따라서 공개 화면의 기록은 본격 운용 결과라기보다 운영 검증 단계의 참고 정보에 가깝습니다.

왜 이 안내가 필요한가

공개 페이지에서 보이는 숫자와 기록이 모두 즉시 투자 권유처럼 보이지 않도록, 운영 권한과 공개 열람의 범위를 구분하기 위해 이 페이지를 둡니다.

어떻게 읽으면 좋은가

공개 페이지는 추천 종목 자체보다 운영자의 판단 흐름과 기록을 참고하는 화면으로 보시는 편이 맞습니다. 특히 보유종목과 매매이력은 테스트 운영 맥락을 함께 보셔야 합니다.

Practical Note

실제 화면에서는 이렇게 이해하시면 됩니다

공개된 운영 기록을 너무 강하게 해석하지 않도록, 자주 생기는 오해를 먼저 적어 둡니다.

보유종목

실제 관리자 기록입니다

화면에 보이는 보유 목록은 관리자만 입력하거나 갱신할 수 있는 기록입니다. 사용자 참여형 목록이 아닙니다.

매매이력

운영 로그에 가깝게 봐야 합니다

과거 체결 기록은 “이 전략을 무조건 따라 하라”는 뜻이 아니라, 현재 어떤 기준으로 테스트 중인지 보여주는 운영 흔적입니다.

현재 단계

지금은 소액 테스트 운영입니다

운영 규모보다 검증 맥락이 더 중요합니다. 수익 숫자만 떼어 보기보다 실험 단계라는 전제를 함께 보셔야 합니다.
