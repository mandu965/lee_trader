Editorial & Corrections

편집·정정 정책

Lee Trader Lab은 금융 정보를 다루는 사이트로서 누가 어떤 근거로 글을 작성하고, 오류를 발견했을 때 어떻게 수정하는지 공개합니다. 이 정책은 시장 해설, 블로그, 방법론, 용어 설명과 공개 운영 안내에 적용됩니다.

핵심 원칙

속도보다 정확성, 확신보다 근거, 결과 홍보보다 한계 설명을 우선합니다. 모델 점수와 실제 주문 결과를 구분하고, 확인되지 않은 내용을 사실처럼 작성하지 않습니다.

작성·검토 주체

콘텐츠는 사이트 운영자가 직접 기획하고 최종 검토합니다. 화면의 “Lee Trader Lab 편집팀”은 외부 기자 조직이 아니라 운영자와 자동화된 데이터 검증 절차를 함께 지칭하는 사이트 표기입니다.

콘텐츠 목적

국내 주식 데이터, 모델 출력, 시장 구조와 운영 기록을 이해하기 쉽게 설명합니다. 개별 이용자를 위한 맞춤 투자 자문이나 수익 보장 콘텐츠는 작성하지 않습니다.

최종 책임

자동 생성 도구나 AI가 초안 작성을 보조할 수 있지만 공개 여부와 사실 확인, 표현 수정, 최종 책임은 운영자에게 있습니다.

Source Review

자료 선택과 검토 절차

시장 가격과 거래량, 투자자별 거래, 기업 재무처럼 사실 확인이 필요한 항목은 한국거래소, 금융감독원 전자공시, 증권사 OpenAPI와 사이트 내부 운영 산출물을 우선 확인합니다. 외부 기사나 커뮤니티 글은 사실의 단독 근거로 사용하지 않습니다.

모델과 정책을 설명할 때는 실제 운영 코드, 설정, 산출물의 기준일을 대조합니다. 연구용 열과 운영 적용 열, shadow 결과와 실제 주문 결과를 구분합니다. 운영에 적용되지 않은 실험값을 현재 서비스의 공식 결과처럼 표현하지 않습니다.

시장 해설은 관측 가능한 데이터와 운영자의 해석을 구분해 작성합니다. “상승 종목 비율이 낮다”는 관측과 “추격보다 관찰이 적절하다”는 해석은 성격이 다릅니다. 가능한 경우 기준일과 판단 근거를 함께 적습니다.

1. 기준일 확인

가격·수급·재무·시장 상태의 기준일이 서로 맞는지 확인합니다. 오래된 데이터가 섞이면 최신 분석처럼 게시하지 않습니다.

2. 운영 근거 대조

점수 공식과 상태 설명은 현재 운영 코드와 산출물을 확인합니다. 변경 이력이 있으면 기존 글의 수정 필요성도 함께 검토합니다.

3. 과장 표현 제거

“확실한 상승”, “무조건 매수”, “수익 보장”처럼 근거 범위를 넘어서는 표현을 사용하지 않습니다.

AI Assistance

AI와 자동화 도구 사용 원칙

Lee Trader Lab은 데이터 처리, 초안 구성, 문장 교정, 반복 검사에 자동화 도구와 AI를 사용할 수 있습니다. 그러나 도구가 만든 문장을 검토 없이 게시하지 않습니다. 특히 점수 공식, 가중치, 운영 상태, 체결 결과처럼 정확성이 중요한 내용은 코드와 원자료를 다시 확인합니다.

AI는 공시되지 않은 사실을 추정하거나 특정 기업의 미래를 단정하는 출처가 될 수 없습니다. 출처가 필요한 사실은 공식 자료를 우선하고, 확인할 수 없는 내용은 삭제하거나 불확실성으로 표시합니다.

자동 생성된 시장 요약도 데이터 기준일과 필수 값이 정상인지 확인하는 절차를 거칩니다. 데이터가 비었거나 서비스가 갱신 중이면 강한 결론 대신 보류 상태를 표시하는 것을 원칙으로 합니다.

Corrections

오류 수정과 정정 절차

오탈자처럼 의미에 영향을 주지 않는 수정은 발견 즉시 고칠 수 있습니다. 계산 방법, 수치, 기준일, 정책 상태처럼 독자의 판단에 영향을 줄 수 있는 변경은 본문 내용과 수정일을 함께 갱신합니다.

중대한 오류가 확인되면 잘못된 내용을 조용히 유지하지 않습니다. 해당 문장을 수정하고, 필요한 경우 무엇이 왜 바뀌었는지 본문에 정정 메모를 남깁니다. URL은 가능한 한 유지해 기존 링크와 검색 기록이 끊기지 않도록 합니다.

오류 제보는 mandu965@naver.com으로 받습니다. 메일에 페이지 URL, 문제가 되는 문장, 확인 가능한 근거를 포함하면 검토에 도움이 됩니다. 접수 내용은 사실 확인 후 반영하며, 특정 종목에 유리한 서술을 요구하는 요청은 받아들이지 않습니다.

경미한 수정

맞춤법, 깨진 링크, 읽기 어려운 문장처럼 결론을 바꾸지 않는 오류를 바로잡습니다.

실질적 수정

계산 공식, 수치, 운영 적용 여부가 달라지면 modified 날짜와 관련 설명을 갱신합니다.

삭제·비공개

근거를 복구할 수 없거나 중복·저가치인 글은 광고와 목록에서 제외하고 필요하면 검색 색인도 중단합니다.

Independence

이해상충과 광고 독립성

사이트는 운영자의 개인 투자 경험과 실제 운영 데이터를 바탕으로 작성됩니다. 운영자가 글에 언급된 종목을 보유할 가능성이 있으므로, 공개 콘텐츠를 특정 종목의 거래 유도로 사용하지 않고 종목별 맞춤 추천을 제공하지 않습니다.

광고가 표시되더라도 광고주가 콘텐츠 주제, 종목 평가, 시장 해석이나 수정 여부를 결정하지 않습니다. 협찬이나 경제적 대가를 받은 콘텐츠를 게시하게 될 경우 일반 편집 콘텐츠와 구분할 수 있도록 명확히 표시합니다.

사이트의 자동매매 운영 결과는 성공 사례만 선택해 홍보하지 않습니다. 손실, 주문 차단, 데이터 부족, 검증 실패도 분석 대상에 포함하며 모델과 계산식을 바꾸기 전에 원인을 먼저 기록합니다.
